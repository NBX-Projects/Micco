## ✨ Destaques do Micco

* **Áudio Cristalino com IA:** Redução de ruído avançada com modelos neurais em tempo real (DeepFilterNet e RNNoise) para eliminar ruídos de fundo e teclados mecânicos.
* **Baixa Latência:** Infraestrutura baseada em WebRTC SFU de alto desempenho para conversas fluidas sem atraso.
* **Multiplataforma Nativo:** Aplicativo disponível para Windows, Linux, Android e versão para navegadores.
* **Compartilhamento de Tela Fluido:** Transmissão de tela com suporte a aceleração de hardware e controle dinâmico de taxa de quadros e bitrate.
* **Atualizações Automáticas:** O aplicativo verifica e instala as versões mais recentes silenciosamente e com validação de integridade criptográfica (SHA-256).

## 🔒 Segurança e Integridade

Todos os executáveis oficiais do Micco publicados neste repositório passam por pipelines de compilação automatizados via GitHub Actions com compilação determinística e geração de hashes SHA-256.

Para conferir o hash no Windows (PowerShell):
```powershell
Get-FileHash -Algorithm SHA256 Micco-Setup-*.exe
```
